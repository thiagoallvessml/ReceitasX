Guia de Campo: Como ler os dados no Supabase Dicionário Oficial

Quando você abre a tabela cliques_afiliados no painel do Supabase, aqui está a explicação de cada coluna técnica:

badge afiliado_codigo

É o código que o parceiro divulgou (ex: ?ref=DOCECOLE10). Nossa página cruza com a tabela de afiliados para mostrar o Nome Real e o Email da pessoa.

link pagina_destino (Link)

Qual link específico o lead abriu: /acesso-vitalicio (oferta premium), /comecegratis ou /checkout.

share referrer (Origem)

O site ou aplicativo de onde o visitante veio (Instagram, TikTok, WhatsApp). Se estiver vazio (null), foi um acesso direto ou via app com bloqueador.

devices user_agent (Aparelho)

Identifica o dispositivo exato: se é iPhone (iOS), Android ou Computador, e o navegador utilizado (Safari, Chrome, Instagram WebView).

schedule created_at

Carimbo de data e hora UTC do momento exato do clique. Nossa tela converte automaticamente para o horário de Brasília (UTC-3).

fingerprint id (UUID)

Identificador único universal daquele clique. Permite rastreamento pontual e previne duplicidades.

lightbulb Dica: Para simular e ver um clique entrando no Supabase agora mesmo, clique em "Simular Clique de Teste".

Políticas de Segurança e Permissões (Supabase RLS)

Verifique se as permissões estão ativas para gravação de novos cliques e leitura do administrador.

Script de Correção e Permissões (cliques_afiliados) 
-- Garante acesso de inserção anônima (visitante clicando no link)
CREATE POLICY IF NOT EXISTS "cliques_anon_insert" ON cliques_afiliados FOR INSERT WITH CHECK (true);
GRANT INSERT ON cliques_afiliados TO anon, authenticated;

-- Garante que admin e autenticados consigam ler
CREATE POLICY IF NOT EXISTS "cliques_admin_select" ON cliques_afiliados FOR SELECT
  USING (EXISTS (SELECT 1 FROM perfis WHERE perfis.id = auth.uid() AND (perfis.role = 'admin' OR perfis.plano = 'admin')));
GRANT SELECT ON cliques_afiliados TO authenticated;

-- Índices de performance para relatórios ultra-rápidos
CREATE INDEX IF NOT EXISTS idx_cliques_afiliados_codigo ON cliques_afiliados(afiliado_codigo);
CREATE INDEX IF NOT EXISTS idx_cliques_afiliados_created_at ON cliques_afiliados(created_at DESC);
